ICOCA · 교통비

ICOCA = 간사이 교통카드(한국 티머니와 같음). 전철 · 지하철 · 편의점에서 찍기만 하면 됨.
성인 3 · 소인 1 (만 11세 = 일본 초등학생 = 어린이 요금, 대부분 성인의 절반).

사는 법 (간사이 공항 도착 때, 10~20분)

  1. 입국 후 간사이 공항역 JR 매표소(미도리노 마도구치)로 감
  2. 여권을 보여주고 ICOCA 4장 구매. 1장 2,000엔 = 보증금 500엔 + 충전 1,500엔
  3. 아이 카드는 "어린이 ICOCA(こどもICOCA)"로 달라고 함. 성인 카드를 쓰면 성인 요금이 빠짐
  4. 모자라면 역 충전기에서 현금으로 충전(1,000엔 단위)
  5. 귀국 날 공항 JR 매표소에서 반납하면 보증금 500엔 + 남은 금액 환불(수수료 220엔). 기념으로 가져가도 됨

어린이 ICOCA 를 외국인에게 파는지는 확인 못 함 → 매표소에서 문의. 안 되면 아이는 역에서 어린이 표를 따로 삼.
갤럭시 S26 · S20 = 일본 모바일 ICOCA 사용 불가(실물 카드 필요). 아이폰 지갑 앱 ICOCA 는 확인 못 함.

예약하는 법

  1. 네이버 지도에서 "도톤보리 맛집" 검색
  2. 왼쪽 위 "맛집 예약" 필터 누르기
  3. 식당 고르고 "예약하러 가기" → 타베로그 예약 페이지
  4. 날짜 · 4명 · 시간 입력, 메모에 "외국인, 아이 1명"

2~3주 전에 예약. 18일은 수요일 저녁. 예약 버튼이 없는 식당은 현장 대기.
예약하고 안 가면 취소 수수료가 나올 수 있음.
